#  ПРИМЕЧАНИЯ ДЛЯ v9.0 ULTRA
# ══════════════════════════════════════════════════════════════════════════════
#
#  1. TLS SPOOFING (curl_cffi):
#     - Discord и Cloudflare детектят Python по TLS-отпечатку (JA3/JA4).
#     - curl_cffi подменяет отпечаток под Chrome 120/124.
#     - Если установка не удалась — скрипт fallback на requests.
#     - Windows: требуется Visual Studio Build Tools (C++ build tools).
#
#  2. HTTP/2 (httpx):
#     - Discord поддерживает HTTP/2.
#     - httpx[http2] делает запросы похожими на реальный браузер.
#     - Улучшает обход WAF и снижает вероятность 403 ошибок.
#
#  3. GATEWAY (websocket-client):
#     - Используется для получения списка участников (op 14 Lazy Request).
#     - Обходит REST API лимиты на /guilds/{id}/members.
#     - Позволяет получать до 1000 участников за один запрос.
#
#  4. ОБРАБОТКА МЕДИА (Pillow):
#     - Конвертация и сжатие изображений перед загрузкой.
#     - Discord лимиты: иконки ≤ 256KB, баннеры ≤ 10MB.
#     - Автоматическое определение формата по magic bytes.
#
#  5. RETRY (tenacity):
#     - Автоматические повторные попытки при сетевых ошибках.
#     - Экспоненциальный backoff: 1s → 2s → 4s → 8s → ...
#     - Учет заголовка Retry-After при 429 ошибках.
#
#  6. ЗАДЕРЖКИ (2-5 секунд):
#     - Реализованы в cloner.py через human_delay().
#     - Между созданием ролей: 2-5 сек (рандом).
#     - Между созданием каналов: 2-5 сек (рандом).
#     - Batch паузы: каждые 3 роли → 12 сек, каждые 8 каналов → 10 сек.
#     - Это предотвращает 429 ошибки и блокировки аккаунта.
#
#  7. GEVENT vs EVENTLET:
#     - gevent РЕКОМЕНДУЕТСЯ для Python 3.10+.
#     - eventlet имеет известные проблемы с Python 3.11+.
#     - Если gevent не компилируется на Windows:
#       pip install gevent --only-binary :all:
#
#  8. ПРОКСИ:
#     - pysocks: SOCKS4/SOCKS5 для requests.
#     - aiohttp-socks: SOCKS4/SOCKS5 для aiohttp.
#     - Формат: socks5://user:pass@host:port
#
